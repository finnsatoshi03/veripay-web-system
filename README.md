# Veripay Web System

> Smarter Payroll. Seamless HR.

This project is currently under active development. The repository has been initialized with the core libraries and basic setup, but the full implementation is ongoing.

## 📝 Project Overview

Veripay is an all-in-one web-based payroll and HR management system that streamlines:

- Attendance tracking
- Leave requests
- Payslips management
- Employee reporting
- Real-time biometrics integration

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Yarn (v1.22 or higher)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/veripay-web-system.git
cd veripay-web-system
```

2. Install dependencies:

```bash
yarn install
```

3. Start the development server:

```bash
yarn dev
```

4. Build for production:

```bash
yarn build
```

### Available Scripts

- `yarn dev` - Start development server
- `yarn build` - Build for production
- `yarn preview` - Preview production build
- `yarn lint` - Run ESLint
- `yarn type-check` - Run TypeScript type checking

_Note: This is an ongoing development. The repository currently contains only the initialized libraries and basic project structure._
